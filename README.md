# Walmart Sales Analysis & Interactive Dashboard

## 📌 Project Overview

This project analyzes Walmart weekly sales data to understand **store performance, sales trends, monthly sales patterns, and holiday sales impact**.

The project uses **Python, MySQL, and Power BI** to perform data analysis, SQL analysis, and interactive data visualization.

---

## 📊 Dataset

The dataset contains **6,435 records** of Walmart weekly sales.

### Columns

| Column       | Description                                   |
| ------------ | --------------------------------------------- |
| Store        | Walmart store number                          |
| Date         | Week/date of sales                            |
| Weekly_Sales | Weekly sales amount                           |
| Holiday_Flag | Indicates whether the week was a holiday week |
| Temperature  | Temperature during the week                   |
| Fuel_Price   | Fuel price during the week                    |
| CPI          | Consumer Price Index                          |
| Unemployment | Unemployment rate                             |

---

## 🔍 Project Workflow

### 1. Data Analysis using Python

Used Python and Pandas to:

* Understand the dataset structure
* Check data types
* Check for missing values
* Check for duplicate records
* Perform basic exploratory data analysis (EDA)
* Analyze sales by store
* Analyze monthly sales
* Compare holiday and non-holiday sales
* Analyze sales trends over time

### 2. SQL Analysis using MySQL

Loaded the prepared dataset into MySQL and used SQL queries to analyze:

* Total sales
* Average weekly sales
* Total sales by store
* Top-performing stores
* Monthly sales
* Holiday vs. non-holiday sales
* Highest weekly sales
* Average sales by store

### 3. Power BI Dashboard

Created an interactive dashboard containing:

* **Total Sales KPI**
* **Total Sales by Store**
* **Total Sales by Month**
* **Sales Trend Over Time**
* **Holiday vs. Non-Holiday Sales**
* **Average Weekly Sales by Store**
* **Store Slicer**
* **Date Range Slicer**
